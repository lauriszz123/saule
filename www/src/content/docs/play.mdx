<Aside type="caution" title="The browser runtime is still being built">
	The editor, examples and link sharing all work now. **Running** code does

### What works today

- A full editor with Saule syntax highlighting, bracket matching and history
- Eight worked examples covering types, classes, null safety, pattern
  matching, generics and interfaces
- **Copy link** encodes your program into the URL, so you can share exactly
  what you wrote — the code lives in the fragment and is never sent to a
  server

### Notes on the sandbox

The playground runs in **single-file mode**, the same as `saule run file.sau`:
your program executes top-to-bottom and no `class Main` is required.

`import` is not available, because module resolution needs a filesystem the
browser does not have. Nor are the parts of `Os` and `Io` that touch real
files, processes or the network. Everything else — the full type system,
classes, interfaces, enums, pattern matching, closures, and the `String`,
`Math` and `Table` libraries — behaves exactly as it does locally.
