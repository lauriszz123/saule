Saule is a statically typed, class-oriented scripting language. It reads like
Lua and checks like a typed language: every parameter and field states its
type, `nil` is a thing a type opts into rather than a value any slot can hold,
and the compiler reports what it found before anything runs.

This page is the index. If you are starting from nothing, read
[Introduction](/saule/guides/introduction/) and then
[Your First Program](/saule/guides/first-program/) — about fifteen minutes
together. If you are here to look one thing up, the
[Quick Reference](/saule/reference/quick-reference/) and the
[Grammar](/saule/reference/grammar/) are the two pages that answer most
questions without reading prose.
