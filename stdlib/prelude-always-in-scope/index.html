Prelude (always in scope)

These names are bound at the top of every module — no import required, for these or for any of the static classes below them.

Printing

Section titled “Printing”
print(...any) -> nil

Writes its arguments to stdout separated by tabs, with no trailing newline. Each is rendered as tostring would.

println(...any) -> nil

The same, with a trailing newline. This is the one to reach for.

printf(fmt: string, ...any) -> nil

Formats like String.format and writes the result to stdout, with no trailing newline.

Inspecting a value

Section titled “Inspecting a value”
tostring(v: any) -> string

A readable rendering of any value. For a class instance implementing OpToString this calls its toString(); print, println and .. all render the same way.

type(v: any) -> string

The runtime type name: "integer", "float", "string", "boolean", "nil", "function", "table", or the class name for an instance.

"function" is a runtime tag covering every callable — it is not a type you can write, since a function’s type is its signature, fn(A) -> R.

Failing

Section titled “Failing”
assert<T>(v: T?, msg: string?) -> T

If v is truthy, answers it with the nullability stripped. Otherwise throws msg, which defaults to "assertion failed".

The stripping is the point: assert is how a T? becomes a T when you are prepared to fail rather than handle the absence.

error(msg: string, level: integer?) -> nil

Raises msg as a runtime error, ending the program. The message is shown exactly as written, followed by the stack trace. Present for familiarity with Lua.

level says whose line the error points at, as in Lua: 1 (the default) is the error call itself, 2 the call into the function that raised it, 3 the call one further out. A function that checks its arguments raises at level 2, so the error lands on the line that passed the bad value rather than on the check. A level deeper than the stack points at the outermost call. A level below 1 is itself an error. The stack trace is the same at any level.

It is not the same as throw. A value you throw can be caught by a catch clause of the matching type; an error cannot be caught at all. Use throw for a failure the program is meant to handle, and error only where stopping is the point.

Conversion between types is the as cast, not a function — 3.9 as integer, n as string, "42" as integer (which is integer?, since the text may hold no number). See Language guide §Casting.

Prelude interfaces

Section titled “Prelude interfaces”

These interfaces are in scope everywhere too, so a class can implement them without an import. They carry no behaviour of their own — each one is a contract the language itself looks for, and implementing it is how a class opts into a piece of syntax that would otherwise be refused.

Operators

Section titled “Operators”

One row per operator. The method is what you write; the interface is what you list in implements so the compiler knows to look for it.

a - b OpSub<T, R> fn sub(other: T) -> R
a * b OpMul<T, R> fn mul(other: T) -> R
a / b OpDiv<T, R> fn div(other: T) -> R
a % b OpMod<T, R> fn mod(other: T) -> R
a ^ b OpPow<T, R> fn pow(other: T) -> R
a & b OpBAnd<T, R> fn band(other: T) -> R
a | b OpBOr<T, R> fn bor(other: T) -> R
a ~ b OpBXor<T, R> fn bxor(other: T) -> R
a << b OpShl<T, R> fn shl(other: T) -> R
a >> b OpShr<T, R> fn shr(other: T) -> R
-a OpNeg<R> fn neg() -> R
~a OpBNot<R> fn bnot() -> R
#a OpLen fn len() -> integer
a .. b OpConcat<T, R> fn concat(other: T) -> R
a == b, a != b OpEq<T> fn equals(other: T) -> boolean

compare answers the way C’s strcmp does: negative when self sorts first, zero when they tie, positive when other does. OpIndex / OpNewIndex are Saule’s __index / __newindex.

Everything else

Section titled “Everything else”
Syntax it enables Interface Method to define
for v in instance do Iterable<T> fn iter() -> fn() -> T?
for k, v in instance do Iterable2<K, V> fn iter() -> fn() -> (K?, V?)
tostring(a), print(a), a .. b OpToString fn toString() -> string
local a: C = value Assignable<T> static fn of(value: T) -> C

Assignable is the odd one: it lets a bare T fill a C-typed slot, with C.of doing the conversion at the point of assignment.

Where the standard library looks for them

Section titled “Where the standard library looks for them”

Implementing one of these does not only change what your code can write — parts of the library consult them too, which is usually the reason to bother:

Interface What starts working
OpEq<T> Table.contains, Table.indexOf and Iter.unique compare with ==, so they match by your rule rather than by identity
OpCompare<T> Iter.sortBy orders with <; Table.sort takes a comparator directly and needs no interface
OpToString tostring, print, println, String.join and Table.concat all render through it
Iterable<T> Iter.collect(instance.iter()) drains it into a table, which is how an instance reaches the Iter combinators
OpLen #instance
