Table

A table is one structure doing two jobs: an array keyed by consecutive integers from 1, and a map keyed by strings, integers or booleans. Most of what is here works on the array side; keys and values see both, and map access itself is just t[k] and t[k] = v.

Table is the mutating half of the sequence API: it changes the table it is given, or answers a question about one. For deriving a new sequence — map, filter, reduce — see Iter. No name means two different things across the two halves: Table.reverse reverses in place, Iter.reverse returns a new table.

Changing a table

Section titled “Changing a table”
Table.insert<V>(t: table<V>, value: V, pos: integer?) -> nil

Appends value to the end of the array part, or inserts it at pos, shifting everything from pos onward one place to the right.

Table.remove<V>(t: table<V>, pos: integer?) -> V?

Removes and returns the last element, or the one at pos, shifting the rest left. nil when there is nothing to remove, which is what makes a table usable as a stack without a separate emptiness check.

Table.sort<V>(t: table<V>, cmp: fn(V, V) -> boolean) -> nil

Sorts the array part in place. cmp(a, b) answers true when a must come before b.

For ordering by an extracted key rather than a comparator, see Iter.sortBy, which returns a new table.

Table.reverse<V>(t: table<V>) -> nil

Reverses the array part in place. Iter.reverse returns a new table instead.

Table.clear<V>(t: table<V>) -> nil

Removes every entry, array part and map part alike. The table itself stays the same table, so anything else holding a reference to it sees it empty.

Reading a table

Section titled “Reading a table”
Table.len<V>(t: table<V>) -> integer

The array length — the same number #t gives, as a value you can pass around.

Table.contains<V>(t: table<V>, value: V) -> boolean

Whether value appears in the array part. Compares with ==, so a class implementing OpEq is matched by its own rule rather than by identity.

Table.indexOf<V>(t: table<V>, value: V) -> integer?

The 1-based position of the first == match, or nil. For a predicate search, use Iter.findIndex.

Table.keys<K, V>(t: table<K, V>) -> table<K>

Every key: the array indices 1..#t in order, then the map’s keys in no particular order.

Table.values<K, V>(t: table<K, V>) -> table<V>

Every value, in the same order as Table.keys.

Table.slice<V>(t: table<V>, from: integer, to: integer?) -> table<V>

A new table over the 1-based range, to defaulting to the end. Negative indices count from the end, and an out-of-range slice is empty rather than an error.

Table.copy<V>(t: table<V>) -> table<V>

A shallow copy of both halves. Elements are shared, so copying a table of instances gives a new table pointing at the same instances.

Table.concat<V>(t: table<V>, sep: string?, from: integer?, to: integer?) -> string

Joins the elements with sep between them, rendering each as tostring would. sep defaults to the empty string, and from / to restrict the range.

String.join is the same operation with the arguments the other way round.

There is no Table.unpack

Section titled “There is no Table.unpack”

A function returning “however many values the table holds” has no type Saule can write — the arity is not known until the call runs — so the table is passed as a table.
