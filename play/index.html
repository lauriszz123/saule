    How it works
    Your code runs entirely in your browser — the same compiler and VM thesaule CLI uses, built to WebAssembly. Nothing is sent to a server, so the type checker, the diagnostics and the output are the ones you would get locally. The runtime is fetched the first time you press Run.
    Programs run in single-file mode, like saule run file.sau: top to bottom, with no class Main. import does not work here, nor do the parts of Os and Io that reach for real files or processes. Everything else behaves exactly as it does locally.
    Scripts are saved in this browser only. Copy link puts a program in the URL, which is how one travels to another machine.
