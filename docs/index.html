Documentation

Saule is a statically typed, class-oriented scripting language. It reads like Lua and checks like a typed language: every parameter and field states its type, nil is a thing a type opts into rather than a value any slot can hold, and the compiler reports what it found before anything runs.

This page is the index. If you are starting from nothing, read Introduction and then Your First Program — about fifteen minutes together. If you are here to look one thing up, the Quick Reference and the Grammar are the two pages that answer most questions without reading prose.

Standard library

Section titled “Standard library”

Everything Saule ships with. All of it is in scope with no import — the modules are static classes, not packages.

Preludeprint, println, printf, tostring, type, assert, error — and the interfaces the language itself looks for.
StringUTF-8 aware text: slicing, searching, splitting, joining, padding and formatting.
BytesBuffers that are not text, kept apart from string so a byte can never be mistaken for a character.
MathRounding, arithmetic, trigonometry and randomness, generic over integer and float.
TableThe mutating half of the sequence API: insert, remove, sort, and questions about a table.
IterThe deriving half: map, filter, reduce and friends, eager and fully typed.
Io / FileStandard streams and file handles, with modes and seek positions as real enums.
OsTime, environment, filesystem, and child processes you can talk to while they run.
SauleThe version of the toolchain running your code, and how to degrade gracefully on an older one.
ProjectThe saule.config of the code being run: name, version, root and source directories.
ConventionsThe patterns that repeat across the whole library, and why each one is the way it is.
